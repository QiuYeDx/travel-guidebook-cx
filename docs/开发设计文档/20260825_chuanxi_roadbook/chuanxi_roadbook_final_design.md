# 川西路书最终设计（成都 7 天大环线 v2）

## 结论

2026-09-02 起，项目唯一正式路线改为 2026-09-29 至 2026-10-05 的成都起止 7 天闭环：

成都 → 四姑娘山 → 丹巴中路藏寨 → 八美 → 塔公 → 姑弄村 → 新都桥 → 理塘 →
海子山 → 香格里拉镇 / 稻城亚丁 → 桑堆 → 雅江 → 鱼子西 → 折多山 → 泸定 → 成都。

旧的“深圳往返 10 天毕棚沟—达古冰川短环线”整体退役，不再作为可执行备选。历史实施记录保留用于追溯，但正式攻略、结构化数据和用户可见页面只展示 v2 路线。

首页继续作为真正的总览页：删除仅有标题和一句目标、需要点击才能继续阅读的每日路线卡片，改为直接展开 7 天完整概览。每个日期在首页即可看到路线、里程、车程、海拔变化、住宿、强度、关键时间轴、观星安排与降级提示。

## 背景与目标

- 行程窗口固定为 9 月 29 日成都出发、10 月 5 日回到成都，共 7 天 6 晚。
- 唯一重负荷日为 D3；D2 早睡，D4 完整游览亚丁短线。
- 鱼子西观星从去程移动到 D6，避免观星夜后直接叠加 430 km 高原山路。
- 住宿海拔控制在约 2,500—3,300 m，不在理塘或稻城县城过夜。
- 正式攻略、首页、行程页、每日页、观景页与来源复核数据读取同一组结构化事实。
- 视觉继续使用项目现有的留白、圆角、边框、emerald 强调色和深色模式，不参考来源网页的任何样式。

## 非目标

- 不把到成都前后的集结交通塞进 D1—D7。
- 不承诺鱼子西预约数量、收费、停车入口、通行证渠道或末段路况。
- 不把月出、银河方位、道路、天气、票务和车程写成实时精确事实。
- 不引入地图 SDK、账号、数据库、CMS 或实时车辆接口。
- 不用动画掩盖信息层级；首页是高频阅读页面，以稳定、即时和可扫描为先。

## 用户可见行为

### 首页总览

首屏展示 7 天闭环、约 1,820 km、唯一重负荷日、观星主夜和住宿海拔边界。

首屏下方按 D1—D7 纵向展示完整每日概览：

- 日期、农历、路线标题与强度。
- 当日里程、车程、海拔起终点 / 最高暴露和住宿海拔。
- 3—6 个带明确时间的关键动作。
- 观星状态：主推、可选、休息或返程，不只依赖颜色区分。
- 一条最重要的执行提醒或降级条件。

每日概览本身不是跳转卡片，用户无需进入其他页面才能看懂行程。页面末尾保留“完整攻略 / 行程工具 / 观景目录”作为次级入口。

### 行程与每日页

- 正式编号改为 D1—D7，对应 2026-09-29 至 2026-10-05。
- 行程页继续提供紧凑时间线；每日页补充结构化时间轴、海拔与观星信息。
- D3 明确为唯一赶路日，D4 为园区交通 / 徒步日，D6 为观星主夜。
- 当日停车、通行或开放条件未复核时，不生成假精确导航入口。

### 观景页

- 观景条目同步改为 D1—D7 的四姑娘山、丹巴、塔公、G318、海子山、亚丁、桑堆、鱼子西、折多山与泸定。
- 命名景点使用 `VP-*`，连续车览走廊使用 `SC-*`。
- 没有复核入口的条目保持 `needs-review` 或车览状态，不伪造坐标。

### 正式 Markdown

`content/guidebook/2026-chuanxi-grand-loop.md` 是可讨论、可打印的唯一完整基线，版本为 v2.0。它包含路线总表、每日时间轴、观星窗口、住宿海拔、预约复核、车辆道路、安全停止条件与出发前清单。

## 数据设计

### TripDay 新增内容

- `lunarDate`：农历显示文本。
- `altitudeProfile`：起点、终点、当天最高暴露与说明。
- `timeline`：时间、标题、说明和关键 / 可选 / 休息语义。
- `stargazing`：主推 / 可选 / 休息 / 不安排、参考月出与执行说明。

这些字段是首页与每日页的共同事实源，不在组件中重复硬编码。

### 模块职责

- `content/guidebook/2026-chuanxi-grand-loop.md`：正式攻略与稳定讨论基线。
- `data/trips/2026-chuanxi/trip.ts`：D1—D7、时间轴、海拔、观星、触发器与降级方案。
- `data/trips/2026-chuanxi/viewpoints.ts`：沿途观景、停车等级与停靠预算。
- `data/trips/2026-chuanxi/sources.ts`：参考攻略、政府假期、亚丁政策与道路安全来源。
- `data/trips/2026-chuanxi/planning.ts`：住宿、亚丁、鱼子西、道路和天文复核任务。
- `lib/trip/types.ts` / `schema.ts`：D1 起始编号及新增字段校验。
- `features/trip/overview-dashboard.tsx`：首屏摘要与完整每日总览。
- `features/itinerary/*`：行程时间线和每日执行信息。

## 关键约束

1. D3 是唯一重负荷日，D2 不安排观星或晚间活动。
2. D6 鱼子西未完成官方通行、预约、天气和路面复核时，直接取消，不现场赌路况。
3. D7 必须在睡眠充足后出发；观星延误时优先删除泸定停留。
4. 任何高反重症信号立即下撤、求助或就医，不以吸氧作为继续赶路的理由。
5. 动态来源必须保留 `verifiedAt` / `reviewAt`；来源网页中的估算不能升级为官方事实。
6. 首页 390 px 宽度下不得横向溢出，时间与内容层级必须无需 hover 即可读懂。
7. 不复制参考网页的色彩、卡片或排版风格。

## 降级设计

### B：取消鱼子西，按白天返程

当预约、通行、天气、结冰、能见度、成员状态或车辆条件任一不满足时，D6 取消鱼子西与夜间高海拔停留，在新都桥休息，D7 按原路线回成都。

### C：高原长距离提前下撤

D3—D6 出现道路管制、持续降雪、车辆异常或明显健康风险时，不走陌生支路绕行；在最近成熟城镇停留，并按官方允许与地图推荐路线向康定 / 成都方向下撤。

## 验证策略

- 内容：核对 D1—D7 日期、路线方向、6 晚住宿、海拔、逐日里程和月出估算标识。
- 数据：`npx --yes pnpm@8.7.0 test`
- 静态质量：`npx --yes pnpm@8.7.0 lint`
- 生产构建：`npx --yes pnpm@8.7.0 build`
- 视觉：390 × 844、768 × 1024、1440 × 1000 检查首页、行程、每日、观景与攻略页面。
- 浏览器：检查页面横向溢出、深色模式、控制台错误和首页无需跳转即可读取每日关键事实。

## 已知风险

| 风险 | 影响 | 控制方式 |
| --- | --- | --- |
| D3 约 430 km 高原山路 | 疲劳、迟到与高反叠加 | D2 早睡、06:30 出发、停靠限量、海子山可删 |
| 国庆客流 | 景区预约、酒店、停车与车程波动 | 可退改住宿、D-7 / D-3 复核、不给到达时间作承诺 |
| 鱼子西公开信息不稳定 | 预约失败、夜间路况与结冰 | 默认待复核，失败即执行 B 方案 |
| 月出与银河时刻为估算 | 观星窗口偏差 | D-3 用天文工具按坐标与地形重算 |
| 高海拔低温与天气突变 | 道路、体力与车辆续航波动 | 保暖、提高余量、取消停靠、就近下撤 |
